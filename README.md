# LLAMA D 4.0.6（ローカル実装）

公開版 [LLAMA D 4.0.6](https://www.llamatests.org/tests/LLAMA_D.html) の課題フローを、ローカル実験用に再実装したものです。

## 対応内容

- UI 言語: 日本語デフォルト、日本語 / 英語切替
- 参加者情報: 氏名と ID を入力。ID は 1〜80 文字で、日本語・小文字・数字 1 桁も可
- 音量確認画面あり
- テスト項目: 公式版と同じ 50 音声
- 採点: 最初の 10 項目は練習として記録し、残り 40 項目を 40 点満点で採点
- 正答列: 公式 CGI で満点確認済み
- 出力: `.xlsx`、SheetJS が使えない場合は CSV

## 使い方

```bash
cd LLAMA_D
python3 -m http.server 8766
```

ブラウザで `http://127.0.0.1:8766/` を開きます。

## 結果ファイル

`Meta`、`Wide`、`Trials`、`Events` の 4 シートを出力します。`Trials` には練習項目を含む 50 行が入り、得点対象外の最初の 10 項目は `max_score=0` になります。
